

OpenAPI Generator	
OpenAPI 문서를 보고 자동으로 API 코드를 생성하는 도구

Gradle	
Java 프로젝트를 빌드하고 관리하는 도구

generatorName	
어떤 종류의 API를 생성할지 결정 (우리는 Spring Boot)

inputSpec	
OpenAPI 문서의 위치

outputDir	
생성된 코드가 저장될 폴더

apiPackage / modelPackage	
생성된 Java 파일의 패키지 경로

typeMappings	
OpenAPI 자료형 → Java 자료형 변환

configOptions	
추가 설정 (delegatePattern, oas3, library 등)
