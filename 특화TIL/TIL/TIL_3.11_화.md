# 앱을 만드는 방법

## 1. 네이티브 앱
- **안드로이드**: Kotlin, Java  
- **iOS**: Swift  
- 안드로이드와 iOS가 제공하는 모든 자원과 기능 활용 가능  
- 전통적인 앱 개발 방식으로, 개발이 까다로움  

---

## 2. 모바일 웹 / 웹 앱
- **모바일 웹**: 기존의 웹 화면(PC)을 스마트폰 크기에 맞춘 것 (예: 크롬, 사파리)
- **모바일 웹 앱**: 모바일 웹보다는 앱에 가깝지만 큰 차이 없음
  - 플레이 스토어 등록 ❌  
  - 스마트폰 하드웨어 사용 불가 (카메라, 센서 등)  

---

## 3. 크로스 플랫폼 앱
- **React Native, Flutter**  
- 한 번의 코드 작성으로 안드로이드, iOS 모두 동작하는 앱 개발 가능  
- 하지만 **웹을 따로 개발해야 하므로 제외**  

---

## 4. 앱 내의 웹뷰 개발(하이브리드 앱)
- **내용물은 웹이지만 포장지만 앱인 형태**
- 즉, 앱에서 웹 내용을 불러와서 **웹뷰 형태**로 보여줌  
- **플레이 스토어 등록 가능** ✅  
- **모바일 웹에서는 불가능했던 네이티브 기능 구현 가능** ✅  

### 구현 방식
1. **Cordova, Capacitor 사용** (하이브리드 프레임워크)  
2. **React Native를 이용해 일부 UI 구현하고 메인 콘텐츠는 웹뷰 불러오는 방식**  

[React/React Native 하이브리드 웹뷰 방식으로 웹앱 개발하기](https://velog.io/@bab_shunn/reactreact-native-%ED%95%98%EC%9D%B4%EB%B8%8C%EB%A6%AC%EB%93%9C-%EC%9B%B9%EB%B7%B0-%EB%B0%A9%EC%8B%9D%EC%9C%BC%EB%A1%9C-%EC%9B%B9%EC%95%B1-%EA%B0%9C%EB%B0%9C%ED%95%98%EA%B8%B0)

---

## 5. PWA(Progressive Web App)
- 웹 + 브라우저 API를 활용하여 네이티브 앱처럼 구현  
- **스토어에 등록 가능하지만, 등록하지 않아도 스마트폰 바탕화면에 아이콘 생성 가능**  
- **기본적으로 반응형**  
- `service workers`를 이용한 캐싱을 통해 **로딩 시간 단축 가능**  

### PWA의 네이티브 기능
- [PWA로 가능한 네이티브 기능](https://news.hada.io/topic?id=12762)  
  - 음성 인식, 음성 합성까지 기술적으로 가능

## 앱 유형별 특징  

| 유형 | 특징 |
| --- | --- |
| **네이티브 앱** | 성능이 뛰어나고 하드웨어 활용이 가능하지만 개발이 어려움 |
| **모바일 웹 / 웹 앱** | 간단한 구현 가능, 하지만 하드웨어 기능 사용이 불가 |
| **크로스 플랫폼 앱** | 하나의 코드로 여러 플랫폼에서 동작하지만 웹은 따로 개발해야 함 |
| **하이브리드 앱 (웹뷰 포함)** | 웹을 감싸서 앱처럼 만들 수 있음, 네이티브 기능도 활용 가능 |
| **PWA** | 웹 기반이지만 네이티브 기능도 일부 지원, 빠른 로딩 속도 가능 |

- **서비스가 빠르고 반응성이 필요한 경우**: **Native App**  
- **앱의 성능이나 하드웨어 기능이 매우 필요한 경우**: **Native App**  
- **웹 개발에 익숙하고 빠르게 앱을 구축하고 싶은 경우**: **Hybrid App**  
- **시간과 인력이 부족한 경우**: **Hybrid App**  
- **사용자의 방문이 많고 웹과 모바일 둘 다 고려하는 경우**: **PWA**
