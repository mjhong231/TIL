+ 미들웨어(Middleware) in Express
클라이언트와 서버 사이에서 요청(Request)와 응답(Response)를 가로채서 특정 작업을 수행하는 함수.
Node.js에서 Express를 사용할 때, 미들웨어는 주로 요청을 처리하기 전에 아래 역할
1) 데이터를 변환
요청 데이터를 변형하거나 응답 가공
2) 보안 검사
인증 및 권한 검사 수행
3) 로깅
요청 정보를 콘솔에 출력하는 등 로그 기록을 남길 수 있음
4) 정적 파일 제공
HTML, CSS, 이미지, mp3 파일 같은 정적 파일 제공
